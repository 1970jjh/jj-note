# 📝 JJ 노트 — 노션처럼 쓰는 블록 노트 · 데이터베이스

**바로 써 보기 → https://jj-note.vercel.app** (설치·회원가입 없음)

노션의 핵심 기능(블록 에디터, 페이지 트리, 데이터베이스 보기)을 **순수 HTML·CSS·JavaScript 파일 7개**로 다시 만든 앱입니다.
빌드 도구도, 서버도, 데이터베이스도 없습니다. 내용은 쓰는 사람의 브라우저(localStorage)에 자동 저장됩니다.

## 어떻게 만들었나

Claude Code(Opus 5.5)가 **실제 노션 앱을 리버스 엔지니어링**한 뒤 같은 구조로 다시 구현했습니다.

1. **Aside 브라우저**: 로그인된 노션 화면의 접근성 트리와 스크린샷으로 UI 구성(사이드바·페이지·DB 보드/표·보기 탭·필터)을 파악하고, 내부 API 클라이언트로 데이터 모델을 확인했습니다.
2. **REA(리버스 엔지니어링 MCP)**: 노션 웹 번들을 정적 분석했습니다. React SPA, `/api/v3` RPC, engine.io 실시간 채널, OPFS 위 SQLite 캐시 구조를 확인했습니다.
3. **설계 매핑**: 노션의 «모든 것은 블록» 모델(블록 `type`·`content[]`·`parent`, 컬렉션 `schema` + 여러 `view`)을 «페이지별 블록 배열 + 들여쓰기», «`db = {schema, views, rows}`»로 옮겼습니다.
4. **검증**: Playwright E2E 12단계(입력·마크다운·슬래시·병합·토글·하위 페이지·새로고침 유지·DB 표/보드/캘린더·검색·휴지통·모바일)와 코드 리뷰 에이전트 점검(10건 수정)을 거쳐 Vercel에 배포했습니다.

자세한 분석 내용: [ANALYSIS.md](ANALYSIS.md)

## 기능

| 영역 | 기능 |
|---|---|
| 사이드바 | 페이지 트리(중첩·펼치기·**드래그로 순서/위치 이동**), 즐겨찾기, 검색(Ctrl+K), 홈, 휴지통, 설정 |
| 페이지 | 아이콘(이모지), 커버, 제목, 경로(브레드크럼), 링크 공유, 전체 너비, 복제, 마크다운 내보내기, 인쇄/PDF |
| 블록 에디터 | `/` 명령어 16종 — 텍스트, 제목 1·2·3, 글머리/번호/할 일/토글 목록, 인용, 콜아웃, 코드, 구분선, 이미지, 웹 북마크, 하위 페이지, 데이터베이스 |
| 편집 | 마크다운 단축키, ⋮⋮ 손잡이 드래그 이동, Tab 들여쓰기, 블록 색, 블록 전환·복제, 여러 줄 붙여넣기 자동 블록화 |
| 데이터베이스 | **표 · 보드 · 목록 · 갤러리 · 캘린더** 보기, 필터, 정렬, 검색, 보드/캘린더 드래그, 행 = 페이지(속성 패널 + 본문) |
| 속성 12종 | 텍스트, 숫자, 선택, 다중 선택, 날짜, 체크박스, URL, 이메일, 전화, 담당자, 생성 일시, 최종 편집 일시 |
| 기타 | 라이트/다크 테마, JSON 백업·복원, 모바일 화면 대응 |

## 설치 (내 컴퓨터·내 도메인에 두고 쓰기)

설치 없이 위 주소에서 바로 써도 됩니다. 직접 운영하려면:

```bash
git clone https://github.com/1970jjh/jj-note.git
cd jj-note
python -m http.server 5180      # 또는 npx serve
```

브라우저에서 `http://localhost:5180` 을 엽니다. (`index.html` 을 더블클릭하면 모듈 로딩 제한으로 동작하지 않으니 꼭 로컬 서버로 여세요.)

**내 주소로 배포**: 저장소를 포크한 뒤 Vercel·Netlify·GitHub Pages 어디든 «정적 사이트»로 올리면 끝입니다(빌드 명령 없음).

## 사용법

| 하고 싶은 것 | 방법 |
|---|---|
| 블록 종류 바꾸기 | 빈 줄에서 `/` → `제목`, `할일`, `토글`, `표` 처럼 한글로 검색 → Enter |
| 빠른 서식 | `#` `##` `###` + 스페이스 = 제목 · `-` + 스페이스 = 목록 · `1.` = 번호 · `[]` = 할 일 · `>` = 토글 · `"` = 인용 · ```` ``` ```` = 코드 · `---` = 구분선 |
| 글자 서식 | 드래그 후 Ctrl+B 굵게 / Ctrl+I 기울임 / Ctrl+U 밑줄 / Ctrl+E 인라인 코드 |
| 블록 옮기기 | 줄 왼쪽 **⋮⋮** 를 끌어서 놓기 (클릭하면 삭제·복제·전환·색 메뉴) |
| 들여쓰기 / 토글 안에 넣기 | Tab / Shift+Tab |
| 하위 페이지 | `/페이지` 또는 사이드바 페이지에 마우스를 올려 `+` |
| 페이지 위치 이동 | 사이드바에서 페이지를 다른 페이지 **위(안으로)·위아래 가장자리(순서)** 로 드래그 |
| 데이터베이스 | `/데이터베이스` 또는 사이드바 «새 데이터베이스» → 보기 탭 `+` 로 보드·캘린더 추가 → 열 머리글 클릭으로 속성 이름·유형·정렬 변경 |
| 검색 | Ctrl+K (제목 + 본문) |
| 백업 / 다른 PC로 옮기기 | 사이드바 «설정 · 백업» → JSON 내보내기 → 다른 PC에서 JSON 가져오기 |

## 활용 아이디어 (HRD·교육 담당자용)

- **교육 운영 보드**: 과정을 행으로, `상태(기획→모집→진행→완료)` 보드 + 교육일 캘린더 보기
- **강의 노트·회의록**: 토글로 Q&A 접어 두기, 할 일 블록으로 액션 아이템 관리, 마크다운으로 내보내 메일·블로그에 붙이기
- **교육생 실습 도구**: 바이브코딩 수업에서 «노션을 직접 만들어 보기» 레퍼런스 코드로 사용 — 기능별로 파일이 나뉘어 있어 읽기 쉽습니다
- **사내 배포**: 데이터가 외부 서버로 나가지 않으므로 보안이 까다로운 환경에서 개인 메모장으로 사용

## 알아 둘 점

- 데이터는 **이 브라우저에만** 저장됩니다(약 5MB). 브라우저 데이터를 지우면 사라지니 중요한 내용은 JSON 백업을 받아 두세요.
- 다른 기기 동기화, 실시간 공동 편집, 댓글, 권한, AI 기능은 아직 없습니다.
- 업로드 이미지는 1.5MB 이하만 됩니다(용량 절약을 위해 큰 이미지는 URL로 넣기를 권장).

## 파일 구조

```
index.html        앱 뼈대
css/style.css     노션 스타일 테마(라이트/다크)
js/app.js         사이드바 · 라우팅 · 페이지 화면 · 검색 · 휴지통 · 설정
js/editor.js      블록 에디터(슬래시 명령어, 마크다운 단축키, 드래그, 들여쓰기)
js/database.js    데이터베이스 5개 보기, 필터 · 정렬, 속성 편집
js/store.js       데이터 모델 · 저장 · 페이지 조작 · 마크다운 내보내기
js/ui.js          메뉴 · 모달 · 이모지 선택 등 공용 UI
tests/e2e.py      Playwright E2E 점검 (python tests/e2e.py [URL])
```
